# **DualGene Text Synth**  
*A lightweight, evolutionary text generator powered by dual‑gene dynamics and theme assimilation.*

---

## 🌱 Overview  
**DualGene Text Synth** は、従来の言語モデルとはまったく異なるアプローチで文章を生成する、  
**“文体進化型テキストエンジン”** です。

このモデルは、  
- **二重遺伝子（潜伏遺伝子 + 優位遺伝子）**  
- **テーマ遺伝子の同化（assimilation）**  
- **周期埋め込み（polyrhythmic embedding）**  
- **軽量マルコフ遷移**  
- **シミュレーションによる自然選択（evolutionary selection）**  

を組み合わせ、  
**高速・軽量でありながら、独特の“文学的な文体”を生成する**  
という特徴を持っています。

GPU も巨大モデルも不要。  
7MB のコーパスを **数秒で処理** し、  
テーマに染まった“夢のような文章”を生成します。

---

## 🔬 Key Features

### **🧬 Dual‑Gene Architecture**  
各トークンは 2 種類の遺伝子を持ちます。  
- **self gene**（潜伏遺伝子）  
- **dominant gene**（優位遺伝子）

生成中に遺伝子同士が“戦い”、  
勝者の遺伝子が周囲へ伝播します。  
これにより、文体が進化し、テーマが文章全体に染み込みます。

---

### **🌈 Theme Assimilation**  
テーマ語は単なる「重み付け」ではなく、  
**遺伝子レベルで周囲の語を塗り替える** ことで影響を与えます。

その結果、  
テーマが直接登場しなくても、  
文章全体がテーマの“雰囲気”に染まります。

---

### **🔁 Polyrhythmic Embedding**  
3 種類の周期（例：3, 7, 13）を重ね合わせ、  
トークンに周期的な揺らぎを付与します。

これは GPT の位置エンコーディングとは異なり、  
**文体のリズムや癖を自然に生み出す** ための仕組みです。

---

### **⚡ Ultra‑Light Markov Backbone**  
文脈遷移は軽量な Markov 連鎖で行われますが、  
文体の本質は遺伝子と周期によって決まるため、  
**古典的マルコフの“単調さ”がありません。**

---

### **🧪 Evolutionary Simulation**  
本生成の前に、  
500文字 × 5回のシミュレーションを行い、  
遺伝子の勝敗を記録し、  
**強い遺伝子だけを残す** ことで文体を安定化させます。

## 📦 How It Works

1. **コーパスを読み込み、周期埋め込みトークンを生成**  
2. **語彙を構築し、Markov 連鎖を作成**  
3. **各トークンに二重遺伝子を付与**  
4. **テーマ語の遺伝子を周囲へ同化**  
5. **シミュレーションで遺伝子の淘汰を実施**  
6. **最終生成フェーズで文章を構築**
